# GG-O 다국어 공개 테스트 버전

한국 문화 · 즐거움 · 익명 커뮤니티. 베트남 이용자를 위한 브랜드 사이트이며, 기본 언어는 베트남어이며 상단 우측에서 한국어·영어로 전환할 수 있습니다. 선택한 언어는 현재 브라우저에 저장됩니다. 현재 화면은 사진 투표와 익명 커뮤니티로 구성하며 상점은 보류합니다.

## 실행과 확인

Node.js 24 LTS를 권장합니다.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run typecheck
npm run build
```

정적 배포 결과는 `out/`입니다. 사이트 접근 범위는 사용자의 요청으로 공개 테스트로 전환합니다. 접속 시 공개 홈이 열리고, 글 읽기·투표 등 회원 기능에서 로그인 팝업이 나옵니다. 운영자 체험 계정은 `AAAA` / `0000`입니다. 실제 회원·결제·신고 서버는 연결 전입니다.

## 현재 기능

- 자체 테스트 로그인 (`AAAA` / `0000`), 잘못된 입력 안내, 비밀번호 보기, 로그인 유지, 로그아웃

- 베트남어·한국어·영어 홈·상품·주문·게시판·안내·오류·설치 화면
- 포스터 제목·설명·버튼과 상품 SVG 안의 한글까지 언어별 전환
- 내용과 분리된 팝업 닫기 X, 신고 양식으로 자동 이동
- 회원가입(`/signup/`), 구글·페이스북 연동 준비 코드와 콜백
- 제공된 약관/개인정보 문서와 베트남어·영어 전체 번역, 필수 동의, 무료 Local Storage 동의 저장
- 상점 대신 사진·이름 중심의 투표 목록, 큰 사진과 상세 설명 팝업
- 운영자 전용 투표 등록·편집·삭제와 제목/본문/사진 상세 블록 편집
- 최대 3개 질문·질문별 5개 선택지, 항목당 단일 선택과 전체 응답 제출
- 참여 후 표수·비율 표시, 참여자만 익명 댓글 작성
- 분류·제목·댓글 수·작성일·조회 수가 있는 목록형 익명 게시판
- 익명 글·사진 첨부·익명 댓글·추천·글 저장·검색·정렬
- 모든 글과 댓글의 표시 이름은 ‘익명’. 작성자 댓글 배지, 공개 프로필, 팔로우, 개인 메시지 없음
- 게시글·댓글 신고 → 신고함 → 숨김 또는 기각 → 숨김 해제 테스트
- 신고 대기 건수 표시, 내 보관함, 이벤트 좋아요·싫어요, 매거진
- 이벤트 등록·편집·삭제, 제목·분류·소개·장소·일정·진행 상태·대표 이미지와 카드 미리보기
- 제공받은 로고 이미지를 참고한 워드마크·그래피티 로고·설치 아이콘
- PWA와 3개 언어 오프라인 안내

## 테스트 저장 방식

현재 테스트 UI는 브라우저 localStorage를 사용합니다. 신규 글·댓글·신고·투표와 집계는 현재 기기에서만 보입니다. 실제 서버 권한과 공용 집계는 Supabase 연결 후 활성화합니다. 관리자 신고함(`/#admin`)도 현재 브라우저의 처리 흐름을 테스트하는 화면입니다. 실제 운영자 인증, 다른 이용자의 신고 수신·알림과 실제 결제는 연결하지 않았습니다.

기존 테스트 데이터는 같은 저장 키에서 버전 2 구조로 이전합니다. 기존 장바구니 색상과 주문을 보존하고, 공개 게시글·댓글의 작성자 이름·아이디·아바타와 팔로우 정보는 새 게시판에서 사용하지 않습니다.

## 자산과 데이터

가상의 상품·가격·재고·게시글은 `src/lib/data.ts`에 모았습니다. 상품 그림은 실제 판매 상품이 아닌 자체 SVG 콘셉트입니다. 색상별 SVG 소스는 `scripts/variant-assets.py`로 재생성할 수 있습니다.

로고는 사용자가 이번 대화에서 첨부한 간결한 워드마크 및 블랙 배경 그래피티 이미지를 참고하여 웹용으로 정리했습니다. 원본의 픽셀 추출본이라고 주장하지 않습니다. 사진과 폰트 출처는 `docs/ASSETS.md`를 확인하세요.

## 실제 운영 연결

Supabase 연결 초안과 마이그레이션 001·002를 포함했습니다. 아직 실제 DB에서 실행하지 않았고 UI에도 연결하지 않았습니다. **두 마이그레이션을 모두 검토·적용해야 익명 게시판 권한 구조가 완성됩니다.** 환경변수만 입력한다고 실서비스가 되지 않습니다.

운영 연결·익명성·신고 권한과 검증 범위는 `docs/DEVELOPMENT.md`, 변경 내용과 테스트 방법은 `docs/REVIEW-CHANGES.md`에 기록했습니다.

공개 배포 파일에는 소스 압축파일을 포함하지 않습니다. 테스트 로그인은 클라이언트 UX 체험용이며 서버 보안 인증이나 실제 관리자 권한을 제공하지 않습니다.

소셜 회원가입은 연결 정보가 없어 실제 인증 전입니다. 현재는 안내와 동의 저장을 테스트할 수 있으며, 활성화에 필요한 설정은 `docs/SOCIAL-SIGNUP.md`에 정리했습니다. 브라우저 동의 기록은 기기 간 공유되지 않습니다.

언어 전환 구조, 번역 문구와 이미지 수정 방법, 검증 범위는 `docs/LANGUAGES.md`를 확인하세요.

공개 탐색·로그인 팝업·투표 상세페이지와 서버 연결 준비는 `docs/PUBLIC-BROWSING-AND-POLLS.md`에 정리했습니다. 상점 UI는 보류했으며 기존 코드와 저장 데이터는 보존합니다.
