# 테스트 계정 두 가지

| 아이디 | 비밀번호 | 시점 |
| --- | --- | --- |
| AAAA | 0000 | 일반 사용자 |
| BBBB | 0000 | 운영자 |

아이디는 대소문자를 구분하지 않습니다. 비밀번호는 두 계정 모두 정확히 `0000`입니다. 로그인 팝업에 두 계정을 안내하고 로그인 후 상단 안내줄에 현재 시점과 아이디를 표시합니다. 전환하려면 로그아웃한 뒤 다른 아이디로 로그인합니다.

- AAAA: 게시글·댓글 작성, 투표 참여, 이벤트 읽기/반응, 본인 고객지원 문의 작성·비밀번호 확인. 운영자 메뉴나 임의 운영자 전환 버튼 없음.
- BBBB: 위 일반 기능과 함께 투표글/이벤트 등록·편집·삭제, 신고 관리, 긴급 테스트 요청함, 고객지원 전체 조회·비밀번호 없는 열람·답변.
- 주소에 `#admin` 또는 `#emergency-admin`을 직접 입력해도 AAAA는 관리 화면을 열지 못합니다.
- 실제 소셜 회원의 표시 이름이 BBBB여도 테스트 운영자 권한을 주지 않습니다. 실제 권한은 기존 Supabase 서버 역할 검사로 확인합니다.

## 계정과 기록

기존 AAAA 로그인 기록은 일반 사용자로 복원됩니다. BBBB는 별도로 로그인해야 합니다. 로그인 유지 선택 시 현재 아이디를 Local Storage에, 미선택 시 Session Storage에 저장하며 비밀번호는 저장하지 않습니다. 새로고침해도 선택 계정이 유지되고, 다른 탭의 로그인 정보가 바뀌면 계정/화면 상태를 함께 갱신합니다.

동일 브라우저의 글·댓글·투표글·이벤트·신고 데이터는 공유합니다. 작성자 소유권, 투표 참여와 고객지원 문의 소유자는 두 계정을 구분합니다. 기존 AAAA의 작성 글과 투표 기록을 유지하며, BBBB가 AAAA의 글을 본인 글로 삭제하거나 이미 투표한 것으로 보지 않습니다.

고객지원은 AAAA로 비밀번호를 설정해 작성한 뒤, 같은 브라우저에서 BBBB로 로그인해 전체 조회·답변을 시험할 수 있습니다. 다시 AAAA로 로그인하면 자신의 글 비밀번호로 답변을 확인합니다. 테스트 암호화 저장은 실제 서버 보안을 대신하지 않습니다.

긴급 테스트 요청은 이전과 같이 React 메모리에만 보관하고 새로고침·로그아웃 때 삭제합니다. 따라서 AAAA에서 작성한 긴급 요청을 로그아웃 후 BBBB로 넘기기 위해 개인정보를 브라우저 저장소에 남기지 않습니다. BBBB는 로그인한 탭에서 ‘요청 테스트하기’로 임시 요청함의 열람·처리 흐름을 확인할 수 있습니다. 실제 공유 긴급 접수는 서버 연결이 필요합니다.

이 두 로그인은 공개 사이트 체험용입니다. 실제 Google 계정, Supabase 관리자, 실제 고객 개인정보를 생성하거나 부여하지 않습니다.

최신 통합 관리 주소는 `/#admin`이며 BBBB 로그인 후 상단 대시보드 아이콘으로 엽니다. TOP 글, 게시글/댓글, 매거진, 회원 제한, 언어별 공지는 [TOP-AND-ADMIN.md](TOP-AND-ADMIN.md)를 참고합니다.
