# 주석 반영 내역 · 2026-11-14

## 상품 색상

에크루/블랙 토트백 선택 시 대표 이미지가 에크루 가방·블랙 로고로, 블랙/화이트 선택 시 블랙 가방·화이트 로고로 바뀝니다. 옵션 옆에 작은 색상 미리보기도 표시합니다. 장바구니와 주문에는 선택한 옵션을 보존합니다. 틴트·키링·모자·파우치의 다중 색상도 같은 방식으로 연결했습니다.

테스트: 상품 상세 → 색상 번갈아 선택 → 대표 이미지·선택 표시·미리보기 확인 → 장바구니 담기 → 선택 색상 이미지·이름 확인.

## 익명 게시판

사진 피드를 제목 중심의 목록형 게시판으로 교체했습니다. 전체·자유·뷰티·패션·케이팝·정보 분류, 제목/내용 검색, 최신순/추천순, 저장한 글, 페이지 이동을 제공합니다.

글과 댓글은 모두 ‘익명’입니다. 작성자가 단 댓글도 동일한 이름·스타일이며 작성자 배지나 번호, 공개 프로필 연결을 제공하지 않습니다. 팔로우·팔로잉·개인 메시지는 없습니다. 글 삭제 권한은 이 기기의 소유 표시로만 판정하며, 그 표시는 공개 데이터나 댓글 화면으로 내보내지 않습니다.

테스트: 글쓰기 → 닉네임 입력 없이 등록 → 해당 글에서 댓글 작성 → 다른 댓글과 같은 익명 표시 확인.

## 신고와 처리

각 게시글과 댓글에 신고 버튼을 두었습니다. 사유와 선택 설명을 입력하면 신고함에 즉시 표시되고 헤더 알림에 대기 건수가 나옵니다. 관리 화면에서 게시글 숨김, 특정 댓글만 숨김, 신고 기각, 숨김 해제를 테스트할 수 있습니다. 조치는 게시판과 새로고침 후에도 반영됩니다.

테스트: 게시글/댓글 신고 → 창 닫기 → ‘신고 관리 테스트’ → 숨김 또는 기각 → 게시판 결과 확인. 숨김 처리 탭에서 ‘숨김 해제’도 확인할 수 있습니다.

현재는 **같은 브라우저에만 접수·저장·적용**됩니다. 실제 다른 이용자의 신고 수신, 관리자 인증, 서버 처리와 실시간 알림은 미연결입니다. 서로 다른 이용자의 게시글 신고가 50건 누적되면 우선 숨김 처리한 뒤 관리자가 검토합니다. 같은 이용자의 같은 게시글 신고는 한 번만 접수합니다.

## 로고

사용자가 보낸 이미지 중 두 번째 간결한 워드마크를 헤더·푸터에, 마지막 블랙·화이트·네온 그린 그래피티 로고를 브랜드 영역에 참고·적용했습니다. PWA 아이콘에도 새 워드마크를 반영했습니다.

## 테스트 언어

화면 전체를 한국어로 고정했습니다. 메뉴, 상품·색상, 주문, 게시판, 기본 게시글·댓글, 알림, 오류, 오프라인, 설치와 개인정보 안내를 포함합니다. 통화는 베트남 동을 유지하고 ‘동’으로 표시합니다. 브랜드명·이메일 주소는 식별자로 유지합니다.

## 검증 범위

- DOM 상호작용과 데이터 로직 자동 검사
- 선택 색상과 이미지, 장바구니 옵션, 모의 주문 확인
- 작성자/다른 이용자 댓글의 동일 익명 표시, 공개 데이터에서 소유 정보 제외
- 프로필 없는 글·댓글 작성, 게시글·댓글 신고와 숨김·기각·복원, 저장 후 재복원
- 이전 테스트 데이터의 옵션·게시글 이전, 팔로우·작성자 신원 제거
- 전체 화면 한국어 문구, 로컬 이미지·로고·PWA 파일 참조
- TypeScript와 프로덕션 빌드

브라우저 조작 도구가 제공되지 않아 실제 브라우저 레이아웃·터치·PWA 설치는 이번에도 직접 검증하지 못했습니다. DOM 검사는 실제 브라우저 시각 검증과 구분합니다. Supabase 마이그레이션은 아직 실제 프로젝트에서 실행·검증하지 않았습니다.

## 접속 및 테스트 로그인 후속 수정

사용자가 공개 테스트로의 전환을 명시적으로 요청했습니다. 플랫폼 접근 범위는 공개로 바꾸고 사이트 자체 로그인 화면을 제공합니다. 아이디 `AAAA`, 비밀번호 `0000`으로 입력·로그인·새로고침·로그아웃을 체험할 수 있습니다. 로그인 유지 미선택 시 탭 세션, 선택 시 브라우저 저장소에 상태를 보관하며 비밀번호는 저장하지 않습니다.

이 로그인은 고정 테스트 계정을 이용하는 클라이언트 체험 기능입니다. 서버 보안 경계가 아니고 실제 회원 인증·권한 부여·실제 결제와 연결하지 않습니다. 커뮤니티의 이름은 로그인 아이디와 연결되지 않으며 계속 익명으로 표시합니다.

공개 배포물에서는 소스 압축파일을 제외합니다. 배포 후 쿠키나 인증 헤더가 없는 HTTP 요청으로 한국어 GG-O 로그인 화면이 200 응답인지 별도로 확인합니다.

## 팝업·신고 이동 및 회원가입 후속 수정

팝업 제목·닫기 X는 스크롤 영역 밖의 고정 도구 영역으로 분리했습니다. 내용만 스크롤하며 ESC·외부 영역 클릭·키보드 포커스 관리도 유지합니다. 게시글과 댓글의 신고 양식은 열릴 때마다 해당 위치로 이동하고 사유 선택에 초점을 맞춥니다. 입력 중에는 다시 스크롤하지 않으며, 모션 줄이기 설정을 존중합니다.

회원가입은 `/signup/`에 구현했습니다. 구글·페이스북 선택과 사용자 제공 약관/개인정보 문서 팝업, 가입 버튼 바로 위 필수 체크박스가 있습니다. 동의는 무료 Local Storage에 버전·동의 여부·시각으로 저장하고 중간 인증 상태는 세션을 사용합니다. 실제 소셜 인증은 Supabase·제공자 앱 연결 정보가 없어 미활성 상태로 명확히 표시합니다. 자세한 연결 순서는 `docs/SOCIAL-SIGNUP.md`를 참고하세요.


## 상품 관리·홈·독·고객지원 후속 수정

상품 CRUD·하단 상세·제품정보 접힘 영역, 홈 포스터 재배치, 홈/커뮤니티/스토어/이벤트 독과 반응, 비밀번호 문의와 운영자 답변 체험, 신고 1인 1회 및 50건 임시 숨김을 추가했습니다. 현재 동작 범위와 실제 회원 서버 연결 절차는 `docs/STORE-SUPPORT-AND-EVENTS.md`에 정리했습니다.

## 홈 메인·5개 독·긴급 도움 요청 후속 수정

커뮤니티 포스터를 홈의 앞쪽으로 옮기고 스토어를 간결한 제품 포스터로 변경했습니다. 최신 독은 홈/이벤트/커뮤니티/스토어/긴급이며 이벤트는 네온색 집 아이콘, 긴급은 빨간 경광등 아이콘입니다. 긴급 양식·별도 개인정보 동의·서버 전용 요청함을 준비했습니다. 실제 접수 서버가 없어 현재 전송은 비활성화되어 있으며 브라우저에 긴급 요청 개인정보를 저장하지 않습니다. 연결·검증 절차는 `docs/EMERGENCY-REQUESTS.md`를 참고하세요.


## 커뮤니티 독·긴급 전송 피드백·약관 동선 수정

돌출된 네온색 집 아이콘을 이벤트에서 커뮤니티로 옮겼습니다. 긴급 전송 버튼은 동의 후 누를 수 있고, AAAA 계정에서는 저장·전송 없는 작성 테스트 완료 화면을 표시합니다. 실제 계정의 서버 미연결 상태에서는 접수하지 않은 이유를 즉시 표시합니다. 약관·개인정보 처리방침은 외부 페이지 대신 같은 작성 창 안에서 표시해 회원가입으로 이동하지 않으며 작성 내용과 동의를 유지합니다. 실제 접수는 Supabase와 실제 계정 연결이 없어 아직 사용할 수 없습니다.


## PC 메뉴 통일·기관 연락 안내·AAAA 요청함

PC와 모바일의 주요 메뉴를 홈/이벤트/커뮤니티/스토어/긴급으로 통일했습니다. 긴급 안내에는 베트남어 메시지를 바탕으로 한 한국 기관 연락 지원 취지와 조건부 허위신고 주의 문구, 법령 링크를 넣었습니다. AAAA에는 같은 탭의 테스트 요청을 조회·처리할 수 있는 방패 메뉴를 추가했습니다. 테스트 내역은 새로고침·로그아웃 시 삭제되고 실제 서버 권한은 바뀌지 않습니다.

## 2026-11-16: 일반 사용자·운영자 테스트 계정 구분

AAAA/0000은 일반 사용자, BBBB/0000은 운영자 시점으로 변경했습니다. 앞 절의 AAAA 운영자 설명은 이 변경으로 대체됩니다. 투표·이벤트 관리, 신고 관리, 긴급 테스트 요청함, 고객지원 전체 조회/답변은 BBBB에서 제공합니다. 고객지원의 임의 운영자 전환 버튼은 제거했습니다. 실제 Supabase 역할에는 영향을 주지 않습니다.
