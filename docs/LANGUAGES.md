# GG-O 언어 전환

기본 언어는 베트남어(vi)입니다. 상단 우측의 국기와 KOREAN 버튼을 누르면 한국어로 바뀌고, 같은 자리의 VIETNAM 버튼으로 베트남어에 돌아갑니다. 옆 화살표 메뉴는 KOREAN / VIETNAM / ENGLISH 세 언어를 제공합니다. 영어에서는 빠른 버튼이 VIETNAM을 표시합니다.

선택값은 `ggo-language-v1` Local Storage 키에만 저장합니다. 페이지 재방문·회원가입·법률 안내에서도 유지하며, 다른 탭의 변경을 동기화합니다. `<html lang>`과 앱 설치 manifest도 선택 언어를 따릅니다. 오프라인 안내는 같은 설정을 읽으며 자체 언어 선택을 제공합니다.

## 구현과 수정

- `src/lib/locales/vi.json`, `en.json`: 한국어 원문을 키로 사용하는 정적 번역. `{{0}}` 등의 위치표시는 그대로 유지합니다. 새 UI 문구를 추가하면 두 사전에도 추가해야 합니다.
- `src/lib/i18n.ts`: 주요 포스터 카피, 짧은 메뉴 문구, 통화·날짜, 동적 문구의 매개변수 처리.
- `src/components/locale-provider.tsx`: React가 렌더링하는 텍스트와 접근성·입력 안내 속성을 현지화합니다. 실제 DOM을 사후 수정하거나 새 페이지로 이동하지 않습니다.
- 각 컴포넌트는 `useLocalized()`를 사용하고 표시용 JSX를 `localize(...)`에 전달합니다. 조건문·이벤트 처리·ID·상태·콜백은 원래 값을 사용합니다. 별도 value가 없는 option도 원래 한국어 코드를 명시적으로 유지하며 표시 문구만 번역합니다.
- 사용자가 직접 쓴 글·댓글·문의·회원 아이디·연락처·현위치는 원문을 유지합니다. `translate="no"` 영역으로 보호하며 입력값을 번역기에 전달하지 않습니다. 기본 예시 상품·게시글만 현지화합니다. 직접 등록하거나 편집한 상품 설명도 원문을 유지합니다.
- `src/lib/locales/legal-vi.json`, `legal-en.json`: 제공된 한국어 약관·개인정보 정책 전체의 번역. 문서에는 현재 선택 언어만 표시하며 회원가입 UI는 매 방문 시 직접 동의하도록 기본 해제하며, 2026-11-16 정책 버전과 동의 시각을 저장합니다. 긴급 도움 요청의 별도 동의도 같은 언어로 표시합니다.

번역은 빌드에 포함된 사전을 사용하며 실행 중 번역 API나 유료 서비스를 호출하지 않습니다. 실시간 사용자 글 번역 기능은 포함하지 않습니다.

## 포스터와 이미지

홈 포스터의 큰 제목·설명·분류·버튼은 DOM 텍스트로 구성되어 언어에 맞게 바뀝니다. 로고 GG-O는 동일하게 유지합니다.

이미지 속 한글이 남지 않도록 토트백·파우치·틴트의 7개 원본 SVG에 각각 베트남어·영어 변형을 제공합니다. `npm run localize:assets` 또는 `npm run build`가 `scripts/localize-assets.ts`를 실행해 14개 변형을 생성합니다. 색상과 도형을 유지하고 글자만 교체하며 긴 문구는 지정 영역에 맞춥니다. 새 한글 이미지가 생기면 생성 대상과 `localizedImage` 매핑을 함께 추가해야 합니다. 사용자 업로드 이미지 속 글자는 자동 번역하지 않습니다.

## 검증

`tests/locales.test.tsx`는 3개 언어 전환·저장, 포스터와 이미지, 데스크톱/모바일 메뉴 순서, 주요 화면의 미번역 UI, 입력 중인 글·선택 분류·상품 색상·수량·동의 상태 유지, 법률 문서와 긴급 테스트 흐름을 검증합니다. 기존 한국어 단독 컴포넌트 테스트도 유지합니다.

이번 환경에는 브라우저 화면 도구가 제공되지 않아 실제 화면의 줄바꿈·폰트 크기는 브라우저에서 직접 검증하지 못했습니다. DOM 테스트·타입 검사·정적 빌드와 배포 파일 HTTP 검증을 수행합니다. 실제 회원 인증·관리자 권한·접수 서버의 연결 상태는 이번 언어 전환과 별개이며 바뀌지 않습니다.

## 공개 홈과 투표

공개 홈, 로그인 팝업의 로고 하단 문구, 투표 작성/상세/결과/댓글 UI도 세 언어를 따릅니다. 운영자가 직접 작성한 투표 이름·질문·선택지·상세 블록과 회원 댓글은 원문을 유지하고 기본 예시 콘텐츠만 번역합니다. 질문 선택 중 언어를 바꾸어도 선택과 입력을 유지합니다.
