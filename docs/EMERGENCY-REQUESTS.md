# 홈 포스터·5개 독·비공개 긴급 요청

## 화면과 테스트

홈의 커뮤니티 포스터가 왼쪽/모바일 위로 이동했습니다. 블랙 바탕, 사용자 로고, 네온 그린 타이포와 한 개의 이동 버튼으로 정리했습니다. 스토어는 오른쪽/모바일 아래에서 토트백 이미지와 짧은 문구로 표시합니다.

PC 상단 메뉴와 모바일 독은 공통 메뉴 정의를 사용하며 **홈 → 이벤트 → 커뮤니티 → 스토어 → 긴급** 순서입니다. PC에도 같은 아이콘을 표시하고 매거진은 보조 메뉴·푸터·홈 기사 영역에서 이용할 수 있습니다. 세 번째 커뮤니티는 네온색 배경의 집 아이콘을 위로 조금 올렸고, 이벤트는 일반 달력 아이콘, 긴급은 빨간 경광등 아이콘입니다.

긴급 탭은 사용 대상 안내와 **도움요청하기** 버튼 하나로 시작합니다. 버튼을 누르면 이름·연락처·메일주소·현위치·요청 내용, 별도의 개인정보 수집·이용 안내와 필수 동의, **메세지보내기** 버튼이 나타납니다. 동의하면 전송 버튼을 누를 수 있습니다. BBBB 계정에서는 테스트 완료 화면과 같은 탭의 테스트 요청함까지 확인할 수 있으며, 실제 계정의 서버가 준비되지 않은 경우 바로 이유를 표시하고 접수 성공으로 표시하지 않습니다. 약관과 개인정보 처리방침은 같은 작성 창 안에서 열리고, 닫아도 입력·동의 상태가 유지됩니다. 회원가입 페이지로 이동하지 않습니다. 현위치는 수동 입력이며 GPS를 수집하지 않습니다. 즉각적인 위험에는 112·119를 우선 이용하도록 안내하며, GG-O가 상시 구조·즉시 답변을 제공한다고 표시하지 않습니다.

## 현재 실제 접수는 비활성

이 작업 시 Sites의 프로덕션 환경 변수는 0개이고 Supabase 회원·DB 연결이 없습니다. `BBBB / 0000`은 기존 브라우저 테스트 로그인입니다. 긴급 요청은 일반 고객지원 체험과 구분해서 **실제 서버로의 저장·전송·접수 성공 표시를 차단**합니다. BBBB의 임시 테스트 요청함은 실제 서버 요청함과 구분합니다.

긴급 요청은 React 메모리에만 남습니다. Local Storage, Session Storage, 커뮤니티 게시판 상태, URL, 서비스 워커 캐시, 콘솔 로그에 이름·연락처·메일주소·현위치·본문을 저장하지 않습니다. 등록하지 않고 작성 창을 닫으면 초안은 사라집니다. BBBB가 테스트 등록한 요청은 현재 로그인한 탭에서 최근 50건까지 확인할 수 있고 새로고침·로그아웃 시 삭제됩니다. 실제 개인정보 대신 예시만 입력하도록 안내합니다. 일반 고객지원의 운영자 체험은 실제 긴급 요청함의 권한에 영향을 주지 않습니다.

## 운영자 전용 요청함

서버 어댑터와 UI는 `/#emergency-admin`에 준비되어 있습니다. 실제 서버 요청함의 링크는 서버에서 `admin` 역할을 확인한 회원에게 표시하며, BBBB 테스트 계정은 같은 경로에서 별도의 임시 테스트 요청함을 봅니다. 주소를 추측해서 접속해도 실제 인증과 서버 권한이 없으면 목록·본문을 반환하지 않습니다. 일반 회원과 발신자에게는 접수 목록이나 본문 조회 권한도 부여하지 않고, 발신자는 접수 번호만 받습니다.

운영자는 최근 50건을 상태별로 확인하고, 내용을 열어 이름·연락처·메일주소·현위치·요청·동의 시각을 확인한 뒤 처리 완료로 표시할 수 있습니다. 조회·처리 행위는 서버에서 요청 ID·운영자 ID·동작·시각만 기록하며 개인정보 내용을 로그로 복제하지 않습니다.

## 개인정보 수집·이용

가입 약관 동의를 재사용하지 않고 요청마다 별도로 필수 동의를 받습니다. 초기 체크 상태는 해제이며 수집 주체·목적·항목·보유 기간·동의 거부와 제한·권리 행사 연락처를 버튼 위에 표시합니다. `/privacy/#emergency`에도 같은 내용을 추가했습니다.

동의 버전은 `2026-11-14-emergency-v1`입니다. 서버가 버전과 동의 여부를 재검증하고 실제 인증 회원 ID와 서버 시각으로 기록합니다. 처리 완료 후 30일, 접수일부터 최대 90일을 보관 기한으로 삼습니다. 반복 완료 처리로 기한을 연장하지 않습니다. 기한이 지난 요청은 조회하지 않으며 예약 삭제가 물리적으로 파기합니다.

## 실제 운영 활성화 전 필요한 연결

1. 사용할 Supabase 프로젝트의 공개 URL/anon key와 실제 회원 인증을 빌드 환경에 연결합니다. 브라우저에 서비스 역할 키를 넣지 않습니다.
2. 기존 `001`~`005` 이후 `202611140006_emergency_requests.sql`을 프로젝트 소유자 권한으로 적용합니다. 이번 작업에서는 SQL을 실제 DB에 적용하지 않았습니다.
3. 실제 운영자 계정에만 서버 `user_roles.admin` 역할을 부여합니다. 프로필·경로·클라이언트 값으로 권한을 판정하지 않습니다.
4. 일반 회원 A/B와 운영자 계정으로 권한 검증을 진행합니다. A의 요청을 B와 A의 조회 API가 모두 읽지 못하고 운영자만 조회해야 합니다. 직접 테이블 읽기/쓰기 역시 거부되어야 합니다. 동의 없음·이전 버전·운영자 역할 위조·비로그인 요청은 거부해야 합니다.
5. 운영 주체·연락처·동의 안내·보유 기간을 실제 운영 절차에 맞게 확인한 후 `supabase/setup/enable_emergency_intake.sql`로 예약 삭제와 접수 활성화를 설정합니다. 이 파일은 자동 실행되는 마이그레이션이 아닙니다. 예약 작업 상태와 실제 삭제도 검증합니다.

기본 설정은 꺼져 있습니다. 서버는 접수 설정과 예약 삭제 작업의 활성 상태를 모두 확인해야 접수를 허용합니다. 클라이언트에서도 전송 직전에 서버 상태·동의 버전을 확인합니다. 같은 작성 창의 재시도에는 같은 UUID를 사용하고 서버의 회원/UUID 고유 제약으로 중복 저장을 방지합니다. 성공 응답에 접수 ID가 없으면 완료로 표시하지 않습니다.

## 검증 범위

DOM·서비스 경계 테스트로 독 순서와 이동, 포스터 순서, 개인정보 동의, 서버 미연결/미활성 전송 차단, 일반 회원의 요청함 차단, 전송 오류 후 재시도, 접수 확인 후 입력 삭제, 운영자 화면의 조회·처리 완료, 브라우저 저장소에 개인정보를 남기지 않는 동작을 확인합니다. 실제 Supabase 권한/예약 삭제와 브라우저의 시각·터치 검증은 연결·도구가 없어 실행하지 못했습니다.


## 전송 버튼 후속 수정

동의하지 않았거나 전송 중일 때만 버튼을 비활성화합니다. 버튼을 누르면 입력 내용을 검증하고 서버 접수 상태를 다시 확인합니다. BBBB 계정에서는 입력을 같은 탭의 임시 테스트 요청함에 보관하고 ‘작성·동의 테스트 완료’ 화면으로 이동합니다. 그 밖의 독립적인 양식 체험에서는 임시 요청함에 저장하지 않습니다. 실제로 운영자에게 전송된 요청이 없음을 표시하며 가짜 접수 번호나 실제 접수 완료 문구를 표시하지 않습니다. 실제 계정은 서버가 비활성 상태이면 이유를 표시하고 접수하지 않습니다. 서버가 처음 확인 후 활성화된 경우 작성 내용을 유지한 채 재시도할 수 있습니다. 실제 서버 응답에 접수 ID가 있을 때만 성공을 표시합니다. 실제 서버 연결은 여전히 미완료입니다.


## BBBB 테스트 요청함 메뉴

`bbbb / 0000`도 로그인할 수 있습니다. 로그인 후 상단 방패 아이콘 **긴급 요청함 (테스트)**, 모바일 펼침 메뉴 또는 푸터로 들어갑니다. 긴급 양식을 테스트 등록한 뒤 완료 화면의 **긴급 요청함 보기 (테스트)**로도 바로 이동합니다. 접수·확인 중·처리 완료 필터, 상세 열기와 처리 완료 표시를 제공합니다.

실제 계정의 이름이 BBBB여도 테스트 관리자 경로를 부여하지 않습니다. 실제 서버의 역할 검사와 API 권한은 바꾸지 않았습니다. 테스트 내역은 계정·탭별 React 상태에만 보관하고 다른 계정으로 전환하거나 로그아웃·새로고침하면 비워집니다.

## 기관 연락 지원·허위 신고 안내

베트남어로 상황을 보내면 운영자가 한국 경찰·소방기관 또는 필요한 공공기관과의 연락을 지원할 수 있다는 서비스 취지를 표시합니다. 현재 테스트에서는 실제 신고·기관 연락이 진행되지 않는다는 문구도 함께 표시합니다.

고의로 허위 내용을 보내 공공기관의 업무를 방해한 경우 사안에 따라 처벌될 수 있다는 조건부 표현을 사용합니다. 처벌이 자동 성립하거나 모든 부정확한 메시지가 범죄라고 표시하지 않습니다. 2026-11-14 확인한 국가법령정보센터 자료를 화면의 관련 문구에 연결했습니다.
